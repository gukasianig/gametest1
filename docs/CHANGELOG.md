# История работы и решений

## 5 ноября 2026 — давление волн при кайтинге (A09)

- Решение ассистента по просьбе владельца («сделай как считаешь нужным»): в лимит живых считаются только враги в радиусе 30 м от игрока (`WaveSettings.pressureRadius`), общий предел всех живых — 2× лимит (`absoluteLimitMultiplier`, до 40 при пределе 20). Файлы: `WaveManager.HasRoom()`, `EnemyAI.CountWithin`, `WaveSettings`. Причина — убегающий игрок/бот останавливал волны (далёкие враги занимали предел).
- Проверка (batch `RunSoakBatch`, 300 с бота): PASS — волны идут до конца (волна 37, 176 убийств, пик живых 40 = общий предел, восстановление после освобождения места, детерминированная проверка предела с `pressureRadius=1000`). В промежуточном прогоне бот-уклонист погиб на 256 с (давление теперь настоящее) — soak-бот получил подстраховку (+40 HP при HP<40, счётчик «rescues»; в итоговом прогоне 0). Это покрытие выполнения, не вердикт по балансу. Сложность/плавность для человека не оценены; значения 30 м и ×2 — первое предположение.

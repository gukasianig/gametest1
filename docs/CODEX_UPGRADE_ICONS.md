# Значки карточек улучшений — стиль E (37 штук)

12 ноября 2026 владелец выбрал стиль E после сравнительных листов: потёртая оливковая боевая техника, тёмная сталь, латунь, янтарные лампы, объёмный рисованный вид и свет сверху-слева. Проклятия — красно-чёрные. Единый набор: исходные 26, базовые 9, ChestXp и SteelWill; Evolution сохраняет изображение оружия. Первоначальное требование бирюзового стиля заменено выбором E.

**Формат:** PNG 256×256, прозрачный фон, один предмет по центру, поля ~10%, читается в 64 px, без текста и рамки.
**Куда класть:** `Assets/Resources/UI/Upgrades/<Имя>.png` (имя точно как в колонке «Файл», регистр важен). Код уже подхватывает файл сам; нет файла — рисуется вектор. `.meta` создаст Unity.
**Цвета:** арт E — оливковый/сталь/янтарь, проклятия — красно-чёрные; цвет рамок редкости остаётся под управлением UI. Бейдж «+» рисуется отдельно, в PNG его нет.

## Выбор направления (12.11.2026)

Показаны A — рисованный sci-fi, B — 3D-миниатюры, C — комикс, D — тактические пиктограммы, E — потёртый ретрофутуризм. Затем показан лист B/E по 9 предметов. Владелец выбрал E и поручил изготовить набор для игры.

12.11, готово: 37 отдельных PNG подключены через `PlayerProgression.CardSprite`, у Evolution приоритет остаётся за изображением оружия. `UpgradeArtworkImporter` задаёт alpha, Clamp, Bilinear, без mipmaps и сжатия. `UpgradeArtworkChecks.RunBatch` PASS: все 37 ресурсов, карточки брони/дрона/проклятия, отдельный бейдж, уведомление и возврат в бой. Кадр 1280×720 просмотрен; полный забег и другие разрешения не проверялись.

Исходники, одобренный референс и лист 112/64 px — `docs/art/Upgrades/StyleE/`. Экспорт: `tools/icons/install_style_e.ps1`; GUID существующих PNG сохраняются, временный старый генератор `make_upgrade_icons.py` не запускать поверх E. Все исходники различны по SHA256; альфа проверена у 37 финальных PNG. Приёмка владельцем остаётся открытой.

Полные запросы для каждого значка сохранены в `tools/icons/style-e-jobs.json` (`basePrompt` + `subject`). Для стиля использована правая половина одобренного листа B/E. В финальном арте кристалл янтарный; цвет самого опыта на арене не меняется.

# План развития игры

Обновлено: 1 ноября 2026. Рабочий жанр: аренный шутер на выживание с видом сверху. Это предложения для развития текущего проекта, а не утверждённый список обязательных функций.

## Как пользоваться планом

- `- [ ]` — предстоит сделать или завершить проверку.
- `- [x] ~~Готово~~` — реализовано и проверено в указанном объёме. Зачёркивание сохраняет историю.
- Идентификаторы пунктов постоянные: можно написать «делаем B05».
- После задачи ассистент обновляет соответствующие пункты без напоминаний. У большого частично готового пункта общий флажок остаётся пустым, а законченные части отмечаются отдельными зачёркнутыми подпунктами с датой и объёмом проверки; оставшаяся работа — отдельным пустым подпунктом.
- Приоритеты: **P0** — ошибки и основа, **P1** — первая законченная версия, **P2** — разнообразие и качество, **P3** — большие расширения.
- Сложность: **S** — локальное изменение, **M** — отдельная механика, **L** — несколько связанных систем, **XL** — большой самостоятельный этап. Это не обещание сроков.
- Проверки небольших правок объединяем после завершения системы. Полный аудит всей игры — по явной просьбе владельца. План сам по себе не запускает разработку всех пунктов.
- При продолжении чата читать раздел «Ближайшая очередь» и раздел текущей задачи; весь большой список повторно не загружать.

- Новые идеи (враги, модификаторы, оружие, мета-слой и др.) собраны в [IDEAS.md](IDEAS.md); выбранную идею сначала заносим сюда с постоянным номером. Общий порядок этапов — [MASTER_PLAN.md](MASTER_PLAN.md).

- При работе над улучшениями обновлять также соответствующие UP-пункты в UPGRADE_ROADMAP.md; читать ближайшую очередь и выбранную группу, не весь каталог.

## Когда считать игру полноценной

Не требуется закрывать весь список. Для первой законченной версии достаточно согласованного набора:

- [ ] **Z01.** Есть понятные начало, развитие, цель, победа, поражение и повторный запуск.
- [ ] **Z02.** Основные ошибки закрыты; управление и атаки читаемы, поражение можно объяснить.
- [ ] **Z03.** Один полный забег интересен от начала до конца, а несколько вариантов оружия/улучшений дают разные способы пройти его.
- [ ] **Z04.** Есть законченная арена, обычные враги с разными ролями и хотя бы один проработанный босс.
- [ ] **Z05.** Настройки и важный прогресс сохраняются, ошибки сохранения не уничтожают весь профиль.
- [ ] **Z06.** Визуальный стиль и звук согласованы, интерфейс читается на поддерживаемых экранах.
- [ ] **Z07.** Самостоятельная сборка стабильно работает на целевом компьютере с приемлемой производительностью.
- [ ] **Z08.** Проведена отдельно согласованная итоговая проверка, ограничения известны, версия готова к передаче игроку.

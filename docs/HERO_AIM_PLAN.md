HeroAimChecks PASS (0 runtime errors), два кадра просмотрены. Новые модели/клипы не создавались. Позднее расширено на обычное оружие/опорный хват: HERO_UPGRADE_PLAN.md.

## Исходная причина (до исправления)

- HeroLocomotion уже использует Idle/Run/Hit/Dash/Throw/Death, находит кости плеч, предплечий, кистей и груди. Наличие/качество клипов в игре в этом разборе не проверялись.
- PoseOffhand зеркалит правую руку и совмещает направление левого хвата с правым; собственного наведения на вторую цель нет.
- AutoShoter.Shoot выбирает OtherTarget только при залпе; FireVolley отдельно рассчитывает направление к цели. Оно не обязано совпадать с направлением модели ствола.
- Recoil поднимает оба предплечья общим импульсом. Перед выстрелом AutoShoter также вызывает movement.FaceNow к основной цели.

## Целевая схема

1. Ноги отвечают за перемещение; верх тела — за бой. Сохранить текущие клипы как основу, поверх них корректировать грудь/плечи/локти/кисти существующего скелета. Новая модель и переход всего проекта на другой анимационный стек не нужны для первого этапа.
2. Для Двойных — по устойчивой цели на руку, обновляемой между залпами. Правая и левая руки действительно наводят каждый ствол на свою цель. Сглаживание и удержание цели уменьшают метания между соседними врагами.
3. Корпус помогает рукам: при целях по сторонам — разведённые руки и разворот груди между направлениями. При цели сзади — доворот персонажа; предусмотреть ограничения суставов и плавную смену распределения целей между руками. Для противоположных направлений выбирать устойчивую боковую стойку: простая сумма двух направлений здесь даёт нулевой вектор. Не выкручивать плечо назад на 180°.
4. Порядок кадра: выбор целей → базовая анимация → поза корпуса/решение двух костей каждой руки (IK) → обновление дула → выстрел и эффекты. Согласовать AutoShoter и HeroLocomotion явно; обычного независимого LateUpdate у компонентов недостаточно для гарантии порядка.
5. До выстрела ствол должен смотреть на цель с небольшим допуском; временно недостижимую позу обрабатывать явно. Рекомендуется сперва согласовать стойку/назначение рук; не вводить скрытый запрет задних целей или потерю второго выстрела без отдельного решения по балансу. Скорость наведения/допуск проверить на реальной скорострельности.
6. Отдельные отдача кисти/предплечья, возврат и вспышка у каждого пистолета. Небольшие наклон корпуса при разгоне/торможении и дыхание в покое — после правильного наведения. Throw временно отдаёт левую руку гранате; Dash/Hit/Death имеют приоритет над боевой позой.

# Контекст проекта

Сжато 5 ноября 2026. Подробная хронология — в CHANGELOG.md, проверки и риски — в DEVELOPMENT.md. Прежняя длинная версия этого файла сохранена в Git (коммит 810c45e).

## Состояние

Прототип аренного шутера на выживание, вид сверху: Unity 2022.3.62f3, C#, URP 14.0.12. Рабочая сцена `Assets/Scenes/SampleScene.unity` (пустая `Untitled` игры не содержит). Запуск: `OpenUnity.cmd` → Play → «Старт» → карточка оружия; до выбора время остановлено.

Цикл забега: StartMenu (4 карточки оружия) → бой 600 с (волны, опыт, улучшения по уровням, Esc-пауза) → босс «Страж арены» (2600 HP, три атаки с предупреждениями) → победа (+200 XP) или поражение → результаты → «Заново» (то же оружие) / главное меню.

Проверено программно (batch VerticalSliceChecks, 5 ноября 2026): вся цепочка включая босса, победу, повтор, меню и 300 игровых секунд бота. НЕ проверено человеком/глазами: внешний вид босса, атак, результатов, нового UI; баланс; длительное управление камерой; standalone-сборка.

## Концепция игры (со слов владельца, 5 ноября 2026)

Survival: волны идут на игрока, он отбивается заданное время; когда время выходит, возврат в меню, где что-то открывается или улучшается (мета-прогрессия между забегами). Владелец приглашает предлагать идеи. Сейчас реализован только забег; мета-слой (сохранение, открытия, постоянные улучшения) — пункты L01–L04 роадмапа, не начат. Конкретные механики мета-слоя не выбраны.

Мета-слой (5 ноября 2026, ядро готово): `MetaProgress` — валюта «Детали», сохранение `meta.json`, рекорды, список открытий; «Мастерская» с 4 постоянными улучшениями; награда на экране результатов. Проверено MetaProgressChecks и общим регрессом VerticalSliceChecks (PASS). Не оценены баланс цен/наград и вид экрана; открытия оружия готовы (Дробовик 150, Тяжёлая винтовка 300 деталей); карты, модификаторы забега и открытия по достижениям — следующие шаги (идеи в обсуждении).

## Ключевые параметры (на 5 ноября 2026)

- **Волны:** первая через 2 с, отдых 3 с, интервал спавна 0.75→0.4 с (−0.015/волну), бюджет 10+3/волну (макс. 60), ≤12 врагов за волну, предел живых 6+1/волну (макс. 20), HP врагов +4%/волну. Спавн вне кадра на ≥10 м от игрока, в границах арены.
- **8 врагов (допуск волна/время):** Weak 100 HP (1/0 с), Fast 30 HP (3/25 с), Tank 300 HP (6/75 с), Shooter 65 (4/40), Charger 85 (5/55), Bomber 45 (8/100), Healer 110 (11/140), Splitter 150 (14/180). Первое появление каждого доступного типа гарантировано.
- **Опыт:** кристаллы после смерти Enemy, притяжение 4 м, подбор 0.8 м; кривая уровней 10, 18, 30…; на уровне 3 случайные карточки из каталога с рангами и редкостью. Бонусы прибавляются от базы с пределами (урон ×5, темп ×3, движение ×2, сбор ×3).
- **Оружие:** у записей `weapons` в сцене `range = 0` — код сохраняет дальность самого стрелка (fallback), не удалять без миграции данных. Интервал стрельбы ≥ 0.03 с. Q/W/E/R — отключённая отладка (`enableDebugUpgrades = false`).

## Подводные камни Unity (важно помнить)

- Inspector-данные сцены/префаба переопределяют значения по умолчанию в C#; проверять их перед правкой логики.
- Открытый в редакторе файл сцены держится в памяти: после внешней правки перезагрузить сцену (File → Open); Assets → Refresh этого не делает.
- Нельзя выключать весь объект орбитального оружия внутри его корутины — скрываются рендереры и коллайдеры.
- Сохранять `.meta` и GUID; не переименовывать массово (имена файлов/классов местами не совпадают: `playershoting`/`PlayerShooting`, `Bilboard`, `AutoShoter`).
- `Bullet.Start()` использует параметры, заданные стрелком сразу после Instantiate; пули игрока игнорируют владельца (`SetOwner`).

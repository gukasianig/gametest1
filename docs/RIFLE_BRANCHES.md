## Ассеты

- Воспроизводимый авторский генератор: tools/blender/make_rifle_branches.py; Blender 4.5.15. Использует существующий weapon_kit/creature_mesh и стиль палитры оружия проекта, без внешних скачиваний.
- Редактируемые BLEND, FBX, палитры, прозрачные иконки 512×512 и VERIFICATION.json: docs/art/Weapons/RifleBranches/RifleAssault, RifleMinigun, RifleHeavy.
- Игровые FBX/палитры/URP-материалы: Assets/Art/Weapons/RifleAssault, RifleMinigun, RifleHeavy. Установка только новых записей через Assets/Editor/RifleBranchAssets.cs; прежние модели не переустанавливаются.
- ModelSkinSet: Rifle_Assault/Rifle_Minigun/Rifle_Heavy. Те же изображения — UI/Weapons/Rifle_* и UI/Tree/el_assault/el_minigun/el_heavy. Модель/иконка следуют надетой ветке.
- Blender: замкнутость мешей, отсутствие вырожденных треугольников и повторный импорт FBX PASS у всех трёх; финальные иконки просмотрены после исправления кадрирования. Игровые кадры всех трёх вариантов и мастерской RU/EN 1280×720 просмотрены. В установщике поправлен разворот FBX на 180° по Y; проверка сравнивает source-маркеры GripPoint→Muzzle с направлением героя.

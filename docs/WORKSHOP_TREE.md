# Мастерская: дерево и стихии оружия

Состояние: 5 ноября 2026. Одобренный ориентир — `art/WorkshopTree/Variants/tree_concept_v4_top_down.png`. Внедрено в текущем чате по уточнению владельца; отдельной передачи Claude Code не было.

## Как пользоваться

Главное меню → «Мастерская». Дерево прокручивается колесом/перетаскиванием сверху вниз. Слева четыре прежних постоянных улучшения; в арсенале все 13 оружий. Возле каждого оружия — его собственные огонь, холод, молния и яд. Нажать узел → посмотреть описание/цену справа → купить или улучшить. Для покупки стихии сначала открыть её оружие.

У каждой стихии 3 ранга. Цены покупки очередного ранга: 120 / 220 / 320 деталей. Первое купленное стихийное улучшение оружия активируется автоматически; дальнейшие покупки не заменяют уже выбранную стихию. Купленные варианты можно бесплатно применять/снимать в Мастерской. Одновременно активна одна стихия на оружие; выбор и ранги независимы у каждого оружия и сохраняются между забегами. В бою используется снимок выбранного модуля при выборе оружия.

Линии большого дерева показывают иерархию арсенала и улучшений тела; новые цепочки обязательных покупок между разными оружиями не вводились. Сохранены прежние цены/открытия и постоянные бонусы. Реальное условие для стихий — открыто соответствующее оружие.

## Начальные параметры (баланс ещё не принят)

| Стихия | Эффект |
| --- | --- |
| Огонь | 8 / 16 / 24% урона попадания в секунду на 3 с; сильнейший эффект обновляется, бесконечного накопления нет. Для Стража DPS вдвое меньше. |
| Холод | −20 / 30 / 40% скорости на 2 с; общий нижний предел множителя 0.5, сильнейшее замедление обновляется. Для Стража сила вдвое меньше; только преследование, атаки/рывок без изменений. |
| Молния | До 1 / 2 / 3 уникальных соседей в 5 м; 30% урона попадания, ×0.65 за дальнейший прыжок; общий интервал модуля 0.4 с, цепь не запускает сама себя. |
| Яд | 5 / 10 / 15% урона попадания в секунду на 4 с; до 3 стаков, новые стаки не чаще раза в 0.25 с, частая дробь обновляет последний. Для Стража DPS вдвое меньше. |

Периодический урон и молния не запускают вторичные эффекты повторно. Родные горение огнемёта и холод ледяной пушки сохранены; модуль может дополнять родное поведение. Гранаты/орбитальные спутники не наследуют стихию основного оружия.

## Код и ресурсы

- `Assets/scripts/WorkshopTree.cs`: прокрутка, узлы, линии/ромбы, панель покупки и выбора. `StartMenu.cs` открывает этот экран вместо списка.
- `WeaponElements.cs`: цены, независимые ключи рангов/выбора, снимок модуля и прямое попадание/электроцепь. Данные расширяют существующий `MetaSave.ranks`, версия/старые ключи не менялись.
- `ElementStatus.cs`: ограниченные статусы огня/яда; `SlowEffect` в `SpecialWeapons.cs` задаёт временный множитель движения без перезаписи базовой скорости.
- `AutoShoter.cs`, `bullet.cs`, `SpecialWeapons.cs`: передача стихии по путям основного оружия, включая площадь, турели и дронов.
- `Assets/Resources/UI/Tree/`: 14 новых PNG-значков 256×256 с прозрачными полями и фон 1920×1080. Основные оружия/постоянные улучшения используют прежний ArenaIcons. Рамки, подписи, линии и состояния создаёт UI-код.
- Инструмент: встроенный image_gen. Точные запросы и исходные имена: `art/WorkshopTree/ASSET_MANIFEST.json`. Повторяемая подготовка размеров/полей: `tools/PrepareWorkshopArt.ps1 -SourceRoot <папка исходников>`. Исходные .meta/GUID сохранены, для новых ресурсов Unity создал новые .meta.

## Проверка и остаток

`WorkshopTreeChecks.RunBatch` (без `-quit`, Unity закрыт) — объединённая проверка UI, сохранений, эффектов, четырёх обычных и девяти специальных оружий и мета-цикла; итог PASS. После исправления накопления яда короткий `WorkshopTreeChecks.RunFocusedBatch` также PASS; полный повтор девяти оружий/мета-цикла не требовался. Подробный объём — DEVELOPMENT.md. Проверки используют временное сохранение в памяти и проверочный файл в Logs; данные игрока не подменяются.

Просмотрен снимок настоящего UI 1600×900 из Play (`Logs/workshop-tree.png`). Нужна оценка владельцем: внешний вид в его окне, удобство длинной прокрутки, цены, сила стихий, длительный бой и сочетания с родными эффектами. Standalone и полный аудит игры не проводились.

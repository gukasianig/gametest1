# Старые записи — перенос 16.11 при добавлении наведения героя

## 2026-11-12 — Круг миномётчика: заливка по рельефу

- `EnemyFx.TelegraphFill` теперь собственная сетка (32×6), вершины берут высоту `GroundHeight.At`+0,08 и пересчитываются по мере роста; прежний плоский цилиндр с наклоном резался рельефом и давал видимые треугольники. Затронуты все круги-предупреждения с заливкой (миномёт, телепорт и др.). Компиляция Unity без ошибок; в игре не проверено.

## 2026-11-12 — Музыка при толпе врагов

- Владелец: «ускоряется, когда много врагов». Петли Saw/Flame на музыку не влияют, питч музыки не меняется. Предположение: нехватка кадра/аудиобуфера при толпе. `AudioManager.m_DSPBufferSize` 1024→2048 (меньше срывов звука, чуть больше задержка SFX). Не проверено в игре.

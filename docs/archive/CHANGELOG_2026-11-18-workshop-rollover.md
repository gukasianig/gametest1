# Архив старого изменения

## 2026-11-12 — Враги не пропадают при финальном боссе

- `GameSession.PrepareBoss` больше не останавливает `WaveManager` и не удаляет живых врагов: обычные волны идут во время предупреждения и боя с боссом. Не проверено в игре (нагрузка при боссе + толпе, сложность).

## 2026-11-12 — Толпа не слипается в одну кучу

- Причина: при `PassThrough=true` разведение отключено полностью, все враги шли одним путём. `EnemyAI.Move`: мягкое разведение включено (соседи собираются, враги всё ещё проходят друг сквозь друга, обход `AvoidCrowd` по-прежнему выключен) + личная «полоса» подхода `laneOffset` (веер, действует дальше 5 м от героя). `HealthScale` 1,6→1,3 (просьба «ослабить чуть-чуть»).
- Не проверено в игре: вид толпы и производительность (сбор соседей теперь каждый кадр у каждого врага — если просядет FPS, сделать реже).

## 2026-11-12 — Билд Windows (по просьбе владельца)

- `BuildTools.BuildWindows` через batch: Succeeded, версия 0.1.3, 0 ошибок, 265 МБ, 18 с → `Builds/Windows`. Запуск билда и игровая проверка не выполнялись.

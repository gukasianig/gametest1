# Исправления моделей ArenaGreen для Codex

Дата: 2026-11-08. Проверено Claude: автоматический разбор геометрии всех 286 FBX (`Assets/Editor/GreenArenaModelCheck.cs`, отчёт `Logs/models/geometry.csv`) и листы-превью сверху (`Logs/models/sheet_*.png`, порядок в `index.txt`). Исходные FBX в `Assets/Art/ArenaGreen` не менялись.

## 1. Общая ошибка экспорта (все 286 FBX) — желательно исправить

У каждого FBX в корне поворот −90° по X и масштаб ×100, а меш внутри в сантиметрах и с осью Z вверх. Причина — экспорт из Blender без применения трансформа.
**Как исправить:** перед экспортом `Object → Apply → All Transforms`; в экспорте FBX: `Apply Scalings: FBX All`, `Forward: -Z`, `Up: Y`, включить `Apply Transform`. Проверка: в Unity у корня модели поворот (0,0,0) и масштаб (1,1,1).
Сейчас Claude это компенсирует в коде (`GreenArenaBuilder`), так что арена работает и без переэкспорта.

# F2 · Вулканический шлак

Пробный комплект по образцу F2 из `GroundLookdev/catalog.png`. Модели и карты лежат в `Assets/Art/Arena/F2Clinker/`. В `F2_Clinker.blend` обе сетки и три исходные карты, упакованные в файл.

| Файл | Размер в Unity, X × Y × Z | Назначение |
| --- | --- | --- |
| `F2_Clinker_Tile_8m.fbx` | 8,00 × 0,29 × 8,00 м | Плитка пола. Верхняя кромка на Y=0, рельеф внутри до +7 см, низ на −22 см. |
| `F2_Clinker_RockCluster.fbx` | 2,88 × 1,29 × 2,59 м | Группа скальных обломков. Основание на Y=0. |

- Для пола ставить центры плиток с шагом 8 м по XZ, на одинаковом Y. Для повтора без цветового шва сохранять одинаковый поворот. Спрятать штатный рендерер пола под плитками и оставить его плоский коллайдер. Коллайдеры из FBX для плитки не нужны.
- Для каждого слота материала использовать `F2_Color.png` в Base Map (sRGB), `F2_Normal.png` как Normal Map, `F2_MetallicSmoothness.png` в Metallic Map с источником Smoothness `Metallic Alpha` и выключенным sRGB. `F2_Roughness.png` — исходная карта для Blender. У всех карт 640 × 640 пикселей. Для повторов поставить Wrap Mode `Repeat`.
- `F2_Clinker` использует карты без тонировки. Для `F2_CutEdge` и `F2_FracturedStone` тонировку и силу нормалей можно взять из материалов в BLEND. Если скопление камней служит укрытием, назначить коллайдер вокруг крупных глыб и зарегистрировать препятствие в `ArenaLayout`.

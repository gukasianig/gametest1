# Бриф: текстуры земли для зелёной арены (для Codex)

Дата: 2026-11-08. Заказчик: владелец проекта. Исполнитель: Codex (генерация). Подключает в Unity Terrain: Claude.
Арена 220 × 220 м, вид сверху (камера под углом), стиль единый: **stylized hand-painted, мягкий, без фотореализма**, чтобы сочеталось с low-poly деревьями из `Assets/Art/Packs`.

## Общие технические правила (для каждого набора)

- Размер **2048 × 2048**, PNG, без сжатия с потерями. Допустимо 1024 для вспомогательных.
- **Бесшовность (tileable) по обеим осям обязательна.** Проверить: сдвинуть картинку на 50% по X и Y — шва быть не должно.
- **Без запечённого света и теней.** Никаких бликов, градиента яркости по картинке, виньетки.
- **Без крупных уникальных деталей** (один заметный камень, один цветок, одна палка): они повторяются плиткой и выдают шаблон. Детали — мелкие и равномерно рассыпаны.
- Средняя яркость и цвет указаны в таблице; отклонение внутри текстуры ±10%.
- Файлы на набор: `<имя>_color.png` (sRGB), `<имя>_normal.png` (**OpenGL, Y+**, синеватая), `<имя>_rough.png` (серая, 0 = глянец, 1 = матовая; для земли в основном 0.75–0.95). Для набора «камень» и «грязь» добавить `<имя>_height.png` (серая, для смешивания слоёв).
- Масштаб при подключении: 1 плитка = 8–12 м (по таблице). Мелкие детали в картинке должны читаться на этом масштабе: травинка ≈ 3–6 пикселей.

## Дополнительные карты (для качества и разнообразия)

- **`macro_variation.png`** — 1024 × 1024, серая, бесшовная, очень мягкие пятна (размер пятен 1/3 картинки), чёрный = 0.4, белый = 0.6. Накладывается на всю арену, чтобы убрать повторяемость плитки.
- **`wetness_mask.png`** — 1024 × 1024, серая, бесшовная, мягкие клочья. Для перехода сухо → мокро у воды.
- **Декали с прозрачностью** (PNG с альфой, 512 × 512, вид сверху, без теней), по 3 варианта каждой, накладываются на землю точечно:
  - `decal_leaves` — горсть опавших листьев;
  - `decal_pebbles` — россыпь камешков;
  - `decal_cracks` — трещины в земле;
  - `decal_flowers` — пятно мелких цветов;
  - `decal_footprints` — следы по грязи;
  - `decal_moss` — пятно мха.

## Переходы между слоями

Я смешиваю слои на Terrain по высоте и склону, поэтому нужны `_height.png` у `dirt_path`, `rock_gray`, `rock_mossy`, `gravel`, `mud_wet`: по ним граница получится неровной, как в природе, а не размытой.

## Что НЕ делать

- Не вставлять в текстуры воду, небо, тени, текст, логотипы, людей, следы техники.
- Не менять размер и не обрезать после проверки на бесшовность.
- Не делать разные стили в одном наборе (часть реалистичная, часть рисованная).

## Как отдать

Папка `F:\test game\_incoming\arena-assets\ground\<имя>\`, внутри файлы по правилам выше. Когда готово — сообщить Claude, он подключит слои, раскрасит арену и проверит вид.

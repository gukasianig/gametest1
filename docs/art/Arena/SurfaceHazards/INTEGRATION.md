# Наземные опасности для карьера

Модели лежат в `Assets/Art/Arena/SurfaceHazards/`; префаб огня и `AcidPuddle.fbx` (09.11) — в `Assets/Resources/Hazards/`. Масштаб 1:1, точка привязки в центре зоны на уровне пола. Ставить на высоту поверхности. `SurfaceHazards.blend` содержит кислоту и огонь v1, а `GroundFireKit.blend` содержит детали огня v2 и сборки трёх размеров.

| Модель | Части | Радиус урона при масштабе 1 |
| --- | --- | --- |
| `AcidPuddle.fbx` | `Acid_Stain`, `Acid_Liquid` | ~2,7 м |
| `GroundFireVisual.prefab` | Анимируемая сборка из 14 деталей `GroundFireKit.fbx` | Настраивается в диапазоне 1–6 м |

- У `GroundFireKit.fbx` уже назначены материалы URP `SurfaceHazardsPalette` и `HazardEmissive`. Оба используют прежнюю палитру `SurfaceHazards_Palette.png` с Point, без mip maps и сжатия. Для `HazardEmissive` эта же палитра служит Emission Map.
- Движение через зоны должно сохраняться. Отключить Generate Colliders для мешей, не добавлять их в препятствия `ArenaLayout`. Урон считать по XZ или отдельным триггером. За пределами зоны урон прекращается.
- При замене лужи возле насосной учитывать, что её сетка сейчас объединена с кислотой в разломе внутри `AcidQuarry.fbx`. Новый ассет можно поставить в другой точке или отдельно удалить старую лужу при переэкспорте.

## Огонь v2 в Unity

1. Префаб перенесён в `Assets/Resources/Hazards/GroundFireVisual.prefab` (09.11, GUID сохранён) — его загружает `GroundFireZone`. Поставить `GroundFireVisual.prefab` на ровную поверхность с масштабом объекта `(1, 1, 1)`. Сборка появляется в Play Mode. Начальный радиус задаётся в Inspector, направление ветра — в плоскости XZ.
2. Вызвать `GroundFireVisual.SetRadius(метры)` для плавного изменения видимого радиуса со скоростью 3 м/с. Новые языки поднимаются у края за 0,3 с, а существующие сохраняют опорные точки. Кромка пересобирается по окружности и сохраняет ширину до 0,25 м.
3. Вызвать `SetBurning(false)` при завершении эффекта. Языки опускаются, уже поднятые искры догорают, нагар скрывается через 2,5 с. `SetBurning(true)` зажигает тот же экземпляр снова.

Расчёт урона и размещение в арене остаются у вызывающего кода. При переимпорте `GroundFireKit.fbx` сохранить Read/Write для перестройки кромки и Bake Axis Conversion для локальной оси Y. Файл `GroundFire.fbx` v1 сохранён для существующих ссылок.

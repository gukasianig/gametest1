# Новые силуэты для пиксельной и чернильной серий

[Серия D3/E3](../Living/README.md) заменяет машины живыми существами по уточнению владельца.

07.11.2026. Владелец выделил первые два направления D и E и попросил другие модели. Встроенный image_gen подготовил альтернативные силуэты по тем же ролям. [Запросы](PROMPTS.json) и [номера ролей](../README.md) сохранены.

- [D2 — Аварийная бригада](d2-arcade.png). Пиксельные дорожные машины и городские автоматы. Таранщик на моноколесе, ремонтник-погрузчик, призыватель с двумя желобами для дронов, босс в форме гусеничного завода.
- [E2 — Бродячий театр](e2-ink.png). Рисованные тушью деревянные механизмы. Ходячий колокол, таран с головой барана, две театральные маски у разделяющегося врага, босс в форме часовой башни с противовесами.

Оба листа 1024×1536. Сверены все номера 01–15. D2‑11 выглядит как залповая установка. Если выберут этот вариант, для читаемости миномётчика нужен один наклонный ствол. Снайпер E2‑10 изображён на коротких рельсах, которые относятся к композиции концепта. Масштаб и поведение проверяются при моделировании.

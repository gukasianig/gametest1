# Враги в трёх техниках

[Альтернативы D2 и E2](../Alternates/README.md) развивают два направления, которые выделил владелец. Формы врагов придуманы заново.

07.11.2026. Владелец попросил различать художественную технику, поскольку A–C выглядели как один тип 3D-рендера. Встроенный image_gen создал три новых листа по тем же ролям, без референсов на действующие модели. Точные запросы в [PROMPTS.json](PROMPTS.json).

- [D — Пиксельная аркада](d-pixel.png). Крупный пиксель, ступенчатые края и яркие акценты на тёмном поле.
- [E — Чернильный комикс](e-ink.png). Рисованные механические реликвии, штриховка и оранжевые пятна на бумаге.
- [F — Пластилиновая мастерская](f-clay.png). Скруглённые фигурки, мягкая фактура и конфетные цвета.

Каждый лист 1024×1536 и содержит 14 врагов и босса. [Номера ролей](../README.md) совпадают с первой серией. Ракурс различается по технике. После выбора потребуются игровые ассеты и проверка на боевой камере.

# D3‑01 — пещерный бес

07.11.2026. Уточнённая модель по [пиксельному концепту D3](../d3-mutants.png). Внутренняя часть и ободок каждого уха соединены в одну сетку. Поправлена посадка глаз, клыков и когтей. Длина 1,23 м.

- [Исходник Blender](CaveImp_D3-01.blend) со встроенной палитрой и [FBX для импорта](CaveImp_D3-01.fbx). Отдельная [палитра PNG](CaveImp_Palette.png) доступна для настройки материала в Unity.
- Рендеры модели: [три четверти](three-quarter.png), [сбоку](side.png), [сверху](top.png).
- 2 736 треугольников, девять частей с точками поворота, одна палитра 128×128. Габариты в Blender по XYZ 1.097 × 1.230 × 1.131 м. Нижняя точка лап на Z=0, перед +Y. При подключении `ModelSkins` нормализует размер по старому мешу, поэтому увеличение нужно учитывать в `sizeMultiplier`.

Поза статичная. В Blender 4.5.9 проверены замкнутость частей, отсутствие вырожденных треугольников и повторный импорт FBX с сохранением частей, геометрии, габаритов и палитры. Проверка в Unity впереди. Скрипт сборки `tools/blender/make_cave_imp.py`.

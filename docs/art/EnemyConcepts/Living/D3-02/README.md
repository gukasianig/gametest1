# D3‑02 — быстрый пещерный ящер

07.11.2026. Уточнённая модель по [листу D3](../d3-mutants.png). Секции хвоста согласованы на изгибе, шея лучше стыкуется с головой, опорная задняя лапа получила широкую подушечку. Бирюзовая морда связана по цвету с корпусом.

- [Blender](CaveRunner_D3-02.blend), [FBX](CaveRunner_D3-02.fbx), [палитра](CaveRunner_Palette.png).
- Рендеры [в три четверти](three-quarter.png), [сбоку](side.png) и [сверху](top.png).
- 1 936 треугольников, семь частей с точками поворота, один материал. Blender XYZ 0,780 × 1,420 × 0,732 м, лапа на Z=0, перед +Y.

Blender 4.5.9 проверил замкнутость частей и повторный импорт FBX с геометрией, габаритами и палитрой. Беговая поза статичная. Анимация и проверка в Unity предстоят. Сборка в `tools/blender/make_cave_runner.py`.

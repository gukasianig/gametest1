# D3‑03 — тяжёлый пещерный мутант

07.11.2026. Третья 3D-модель по [листу D3](../d3-mutants.png). Силуэт образуют широкая спина, гребень и тяжёлые передние лапы с опорой на костяшки. После первого рендера поправлена посадка глаз под надбровьями.

- [Исходник Blender](CaveBrute_D3-03.blend), [FBX](CaveBrute_D3-03.fbx), [палитра](CaveBrute_Palette.png).
- Рендеры [в три четверти](three-quarter.png), [сбоку](side.png) и [сверху](top.png).
- 2 402 треугольника, шесть частей с точками поворота, один материал. Blender XYZ 1,740 × 1,470 × 1,226 м. Нижняя точка лап на Z=0, перед +Y.

Blender 4.5.9 проверил замкнутость сеток, отсутствие вырожденных треугольников и повторный импорт FBX с сохранением частей, размеров и палитры. Поза статичная. Подключение к Tank, анимация и проверка в Unity предстоят. Скрипт сборки `tools/blender/make_cave_brute.py`.

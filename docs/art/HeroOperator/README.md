# Герой-оператор — первая 3D-модель

06.11.2026. Настоящая полигональная геометрия из `Assets/Editor/HeroModelBuilder.cs`; PNG/GIF — рендеры этой сетки в Unity 2022.3.62f3 URP. Первая версия для оценки владельцем.

- Unity: `Assets/Art/Characters/HeroOperator/HeroOperator.prefab`, mesh asset, 8 материалов, 16 костей, Legacy-клипы Idle/Run. Один SkinnedMeshRenderer, 8 submesh; 4260 треугольников / 8152 вершины с раздельными гранями. Цвет/эмиссия без растровых текстур. UV повторяются на деталях; уникальной развёртки под рисование текстур пока нет.
- Высота 2 м, подошвы Y=0, перед +Z. Габариты близки к Capsule (высота 2, радиус .5); жёсткие пластины привязаны к одной кости, органической деформации ткани нет.
- Сокеты WeaponSocket (правая кисть), LeftHandGrip и BackSocket. Дульная точка нужна на будущей конкретной модели оружия; сокеты не заменяют существующий firePoint.
- `HeroOperator.obj` + `.mtl` — переносимая статичная поза без костей/анимаций. Анимированный результат — Unity-prefab. FBX/GLB/Blender-файл не создавались.
- `model-views.png` — спереди/сзади/сверху; `run.gif` — цикл 24 кадра/640 мс. Отдельные PNG и `run-frames/` — исходные рендеры.

## Подключение и оставшаяся работа

07.11.2026 prefab подключён в `SampleScene` дочерним объектом Capsule со смещением (0, −1, 0), чтобы поставить подошвы на уровень пола. Rigidbody/CapsuleCollider и firepoint находятся на исходном объекте игрока. Рендереры Capsule и nose отключены. `HeroLocomotion` плавно переключает Idle/Run по горизонтальной скорости, включая короткий рывок. `StartMenu` применяет однотонную окраску только к прототипу без подключённого оператора.

Бег базовый, без root motion, IK и фиксации стоп. Run используется и при движении боком, и при рывке. Нужны модели оружия, поза с оружием, отдача, урон и смерть. Оценка на телефоне и стоимость восьми материалов на Android впереди.

## Проверки и повторная сборка

Opt-in `Tools > Art > Build Hero Operator` / `-executeMethod HeroModelBuilder.RunBatch` создаёт ресурсы/preview scene, не сохраняет SampleScene. Повтор обновляет существующие assets с сохранением GUID; ручные правки генерируемых модели/материалов/prefab будут заменены. Автозапуска при импорте нет.

`VERIFICATION.txt`: сериализованный prefab, 16 костей/8 материалов, высота/подошвы, действительная деформация после Run и bounds. `tools/PreviewHero.cjs`: три вида, 24 кадра с изменением изображения, 640 мс.

## Слои

В `Layers/` семь PNG: `background` — широкий фон; `background_portrait` — отдельно сгенерированная вертикальная композиция фона; `gate` — вход на арену; `workshop` — ремонтная палатка; `conditions` — пульт угроз; `hero` — оператор; `drone` — ремонтный дрон. Пять предметных слоёв имеют настоящую прозрачность. Арт получен встроенным image_gen по выбранному концепту, не программной маской. Это реконструкция для слоёв, не попиксельное восстановление исходника.

Точные запросы и референсы — `LAYER_PROMPTS.json` и `PHONE_BACKGROUND_PROMPT.json`. Текущая компоновка — `phone-scene-data.json` / `phone-animation.js`: реальные размеры PNG, crop и отдельные портретные/альбомные рамки. Холсты слоёв разных размеров; итоговый кадр зависит от экрана. Исходный концепт №4 и остальные варианты сохранены.

`crop = [x, y, width, height]` отсчитывается от верхнего левого угла PNG. Рамки в profiles — нормализованные 0…1, сверху слева. Видимый предмет вписывается в рамку с **единым масштабом обеих осей** и выравниванием снизу: `scale=min(boxWidth/cropWidth, boxHeight/cropHeight)`. Фон заполняет экран через cover-обрезку; не растягивается. `renderer.layout()` возвращает окончательные прямоугольники; `renderer.zones()` — соответствующие зоны выбора. Не растягивать весь прозрачный холст на всю сцену.

## Что движется

Свет ворот и отражение на земле пульсируют; над входом поднимаются слабый пар и искры; лампы пульта мигают с разной фазой; дрон плавно меняет высоту/наклон; герой слегка меняет масштаб по вертикали от опоры у ног (имитация дыхания). Это анимация 2D-слоёв, не 3D-модель и не скелетная анимация персонажа. Плащ не имеет отдельного рига.

Название и подписи рисуются кодом, в PNG их нет. Основные зоны — предметы мира; кнопок-плиток нет. HTML поддерживает `prefers-reduced-motion`: при такой настройке начинает с паузы. Служебные «Пауза»/«Убрать выделение» относятся только к просмотру.

## Передача в Unity

Следующий этап — импорт комплекта в отдельную папку Assets с новыми .meta, привязка зон к имеющимся StartMenu.ShowWeapons / ShowWorkshop / ShowModifiers и воспроизведение эффектов на unscaledTime (в меню timeScale=0). Существующие покупки/сохранения/экран дерева не переделывать ради этого арта.

Для Sprite.Create пересчитать верхний Y crop в нижний: `texture.height - crop.y - crop.height`; pivot героя — снизу. UI должен сохранять aspect ratio: использовать рассчитанный fit-прямоугольник или Image.preserveAspect с нижним выравниванием. Не заполнять рамку раздельным масштабом X/Y, как в первоначальной сборке. Зоны должны совпадать с fitted-геометрией и учитывать настоящий Screen.safeArea в Unity. Подписи доступны без hover; никакой поворот/политика safe area в самом Unity ещё не менялись.

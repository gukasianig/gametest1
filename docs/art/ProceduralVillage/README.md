# Процедурная деревня (Blender)

Скрипт `tools/blender/procedural_village.py` строит кодом, без внешних файлов:
- ландшафт (шум fBm + горное кольцо по краю + озеро), раскраска вершин: трава, песок у воды, земля дорожек и дворов, скалы на склонах, снег на вершинах;
- библиотеку ассетов (коллекция `AssetLibrary`, скрыта): 6 вариантов домиков (1–2 этажа, фахверк, окна, дверь, крыльцо, труба), 4 лиственных дерева, 3 ели, 5 камней, 3 куста, пролёт забора, колодец, бочка, ящик, стог;
- расстановку: колодец в центре на ровном месте, домики на пологих площадках дверью к центру (рельеф под ними выравнивается), дорожки к колодцу, заборы и мелочи у домов, лес кластерами (ели выше по склонам), камни на склонах, кусты.

Объекты расстановки — копии-ссылки на одну сетку библиотеки (правка сетки меняет все экземпляры).

## Запуск

```
F:/blender-x64/blender-4.5.15-windows-x64/blender.exe -b -P tools/blender/procedural_village.py -- --seed 7
```

Параметры: `--seed`, `--size` (м, 200), `--res` (200), `--houses` (14), `--trees` (260), `--rocks` (70), `--out`, `--name`, `--samples` (24), `--no-render`, `--no-fbx`. Одинаковое зерно даёт одинаковый результат. Из окна Blender (Scripting → Run Script) скрипт создаёт новую сцену и не трогает текущую.

Результат в этой папке: `<name>.blend`, `<name>.fbx` (оси под Unity), `<name>_overview.png`, `<name>_village.png`, `<name>.json` (центр, уровень воды, позиции и повороты домиков, счётчики).

## Проверено 09.11.2026 (seed 7)

Blender 4.5.15, фон: 14 домиков, 260 деревьев, 70 камней, 105 кустов, 528 объектов, ≈25 с с рендером. FBX повторно импортирован: 499 мешей, у всех материалы, ≈161 тыс. треугольников. Оба кадра просмотрены. Предупреждения экспортёра FBX «Cannot register a valid material index» для общих сеток на результат не повлияли.

Не проверено: импорт в Unity, коллайдеры, производительность в игре. Стиль — простой low-poly на плоских цветах; ассеты не согласованы с моделями Codex.

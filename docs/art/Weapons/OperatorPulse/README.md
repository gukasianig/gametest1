# Импульсный пистолет оператора

Первый авторский образец оружия для героя. Графитовый корпус, светлые накладки, бирюзовые вставки и латунный ободок эмиттера сочетаются с бронёй героя. Бирюзовая метка на верхней панели видна с высокой камеры.

- [Исходник Blender](OperatorPulse_Pistol.blend), [FBX](OperatorPulse_Pistol.fbx), [палитра](OperatorPulse_Palette.png).
- [Три четверти](three-quarter.png), [сбоку](side.png), [сверху](top.png).
- Длина 0,361 м, 1 436 треугольников, семь замкнутых частей и один материал с палитрой. Перед +Y в Blender. Исходник содержит `GripPoint` и `Muzzle`.

Blender 4.5.9 подтвердил геометрию, габариты и палитру после повторного импорта FBX. В Unity предстоит проверить масштаб, хват и дульную точку. Сборка в `tools/blender/make_operator_pistol.py`.
